# Asset provenance

## Application icon

- Asset: `assets/app-icon-1024.png` and generated Tauri icon variants.
- Created: 2026-08-13 specifically for AI Memory Inspector with OpenAI image generation.
- Prompt intent: a text-free macOS icon combining a shield, stacked local memory layers, and an
  inspection lens; deep navy background with teal/mint foreground.
- Source artifact: generated in the project owner's local Codex session. No third-party logo,
  trademark, user data, photograph, or downloaded stock asset was supplied as input.
- Post-processing: resized to the required 1024×1024 PNG, then converted to platform icon sizes by
  the pinned Tauri CLI. No semantic content was added during conversion.

The asset must be visually reviewed in Finder, Dock, About, and the final DMG on Retina and
non-Retina displays before public release.
