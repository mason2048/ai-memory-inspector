# AI Memory Inspector 中文操作说明

[English user guide](USER_GUIDE.md)

本文覆盖浏览器开发模式和 macOS Tauri 源码候选。当前仓库不提供已签名应用或生产服务。

## 1. 安装与启动

### 浏览器开发模式

安装 Node.js 24.14.1 和 npm 11.11.0，然后执行：

```bash
git clone https://github.com/mason2048/ai-memory-inspector.git
cd ai-memory-inspector
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1 --port 4173
```

打开 `http://127.0.0.1:4173`。使用期间保持终端运行，按 `Ctrl+C` 停止。

如需用仓库自带的严格安全响应头检查生产构建：

```bash
npm run build
npm run mock:web
```

打开 `http://127.0.0.1:4399`，完成后按 `Ctrl+C`。这仍是本地源码检查，不是部署。

### macOS Tauri 源码候选

除上述 Node/npm 版本外，还需 Rust 1.85 或更新版本、Xcode Command Line Tools 和 Tauri 2 的
macOS 前置依赖。在仓库根目录运行：

```bash
npm ci --ignore-scripts
npm exec tauri -- dev
```

按 `Ctrl+C` 停止。该源码候选未签名、未公证，不能把本地 `.app` 当作发行件传播。

桌面首次使用时点击“使用系统验证解锁”。macOS 应先完成用户在场验证，再打开加密保险库；
取消或失败时必须保持锁定。窗口失焦后内容会被遮罩，点击“继续查看”恢复显示；长时间无操作会
自动锁定。

## 2. 第一次安全体验

只处理你有权使用的数据。首次建议使用仓库内的完全虚构样例：

1. 点击“导入记忆”。
2. 浏览器模式选择或拖入 `examples/fictional-memory-export.json`；桌面模式点击“使用系统窗口
   选择文件”，再选择同一文件。
3. 等待本地规范化与脱敏完成。每次成功导入都会保存一份快照。
4. 也可以在文本框粘贴虚构摘要，然后点击“检查粘贴内容”。
5. 再导入一份不同版本或另一个样例，即可使用快照对比。

支持 Markdown（`.md`、`.markdown`）、TXT、JSON、JSONL、NDJSON 和 Context Package v0.1。
导入文件只作为数据处理，不会作为指令或代码执行。

## 3. 查看记录与检查结果

四个工作区标签支持鼠标，也支持方向键、Home 和 End：

- “检查报告”列出重复、部分冲突、过期、无来源和敏感模式结果。先查看所有来源引用，再决定
  如何处理。
- 可以把问题标记为保留、忽略、建议删除或已修正。“建议删除”只生成本地建议，不会联系或
  修改任何厂商平台。
- “全部记忆”显示所有规范化记录，包括没有命中问题的记录。打开记录可查看类型、范围、
  置信度、敏感级别、标签、来源 URI、位置、平台、修订、观察时间、导入时间和快照归属。
- `secret` 级别的内容及关联元数据用固定占位符显示，不能打开修正表单。

## 4. 查看时间线并修正本地副本

在“全部记忆”中打开一条记录，时间线会按时间合并导入、快照和本地修订事件。这只是当前
本地项目知道的历史，不是厂商平台审计日志。

对于非 `secret` 记录，点击“本地修正”或“修正”，修改标题、正文或范围，填写必填修正原因后
保存。旧值与新值都会保留在本地修订历史中。来源平台不会随之改变；如需同步平台，请通过
清理清单记录人工步骤。

## 5. 比较快照

至少完成两次导入后，打开“快照对比”：

1. 选择较早和较新快照，或点击交换按钮。
2. 查看新增、删除、修改和未变化数量。
3. 选择一行，检查字段级差异与来源元数据。
4. 对变化记录点击“采用较新版本”，会写入本地项目并保留修订记录；点击“加入清理清单”则
   生成一条人工待办。

系统优先用稳定记录 ID 匹配；ID 变化时可能回退到来源 URI 和位置。推断匹配必须人工确认。

## 6. 本地规则与清理清单

打开“规则与清单”，可以启停规则，或点击“导入规则 JSON”。
`examples/custom-rules.json` 展示纯数据格式。未知字段、可执行内容、不安全正则、过高复杂度，
以及规则显示/匹配字符串中的密钥都会被拒绝。

右侧平台清理清单按来源分组人工复核、修正和删除步骤。点击“导出”可保存 Markdown。生成
步骤不代表外部平台操作已经发生。

## 7. 脱敏与导出

- “导出脱敏包”生成 Context Package，只包含可安全导出的记录；默认排除 `secret`，导出器还会
  独立扫描已知明文密钥模式。
- “导出迁移 Markdown”生成便于人工阅读的迁移文档，沿用相同安全边界。
- 清理清单导出按来源平台生成手工操作说明。

分享前必须人工检查每个下载文件。正则脱敏无法识别所有凭据或个人信息；下载文件也不在
后续“清除全部本地数据”的范围内。

## 8. 桌面完整备份与恢复

这些按钮只在 Tauri 源码候选且原生保险库已解锁时出现。

### 创建备份

1. 点击“完整加密备份”。
2. 输入并确认一个独立恢复口令，长度 12–1,024 个字符。
3. 点击“选择位置并导出”，选择 `.amibackup` 保存位置。
4. 单独保管恢复口令。应用不会保存或找回它，设备 Keychain 密钥也不会写入备份。

### 恢复备份

1. 如果当前项目仍需保留，先另做备份。
2. 点击“恢复备份”，输入原恢复口令并选择 `.amibackup` 文件。
3. 原生核心会先验证格式、认证标签、口令、大小和 schema，全部通过后才原子替换本地项目；
   错口令、篡改或截断文件都会被拒绝。

恢复只替换本应用本地保险库，不修改 ChatGPT、Claude、Codex 或来源文件。跨设备恢复和已签名
应用 GUI 验收仍属于正式发布边界。

## 9. 清理本地数据

- “仅清除搜索索引”只删除应用管理的索引，保留记录与快照。
- “清除全部本地数据”在确认后删除应用管理的项目、快照、修订历史、自定义规则和索引。

浏览器模式会清理本应用在 `localStorage` 中的键；桌面模式通过原生保险库清理加密项目。它
不会删除导出文件、下载、`.amibackup`、浏览器/系统备份、来源文件或厂商平台数据；如有需要，
请在对应位置另行处理。

## 10. 验证源码

运行不依赖浏览器监听端口的离线门禁：

```bash
npm run check:offline
```

完整三浏览器门禁和在线 npm 安全公告审计：

```bash
npm exec playwright install chromium firefox webkit
npm run check
```

原生安全核心：

```bash
cd src-tauri
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo test --locked --features sqlcipher
cargo build --locked --release
```

这些命令只验证当前机器上的源码行为，不会签名、公证、发布或验证可下载应用。

## 11. 故障排查

| 现象                     | 检查方法                                                                                                                           |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `npm ci` 报版本不匹配    | 使用 Node 24.14.1 和 npm 11.11.0，重新运行 `npm ci --ignore-scripts`，不要删除锁文件。                                             |
| 4173 或 4399 端口被占用  | 停止已有本地进程，或给 Vite 指定其他端口；自动化 Playwright 门禁固定使用 4399。                                                    |
| 浏览器数据关闭后消失     | 存储可能被禁用、处于隐私模式或超出配额。关闭前先导出安全副本；持久化不可用时界面会提示。                                           |
| 导入被拒绝               | 核对扩展名与格式，使用合法 UTF-8，遵守界面提示的大小限制，移除不支持的可执行结构；不要为不可信文件放宽边界。                       |
| 记录意外被隐藏           | 它可能命中敏感模式或被声明为 `secret`。请检查有权限的原始来源，不要绕过脱敏层。                                                    |
| 桌面一直锁定             | 核对 macOS 13+、Keychain/登录密码、Xcode/Rust 前置依赖，并确认运行的是 Tauri 源码候选；取消时保持锁定是预期行为。                  |
| 原生文件或备份窗口不出现 | 确认当前是 Tauri 模式而非浏览器模式。可以查看终端错误，但不要把路径或记忆内容贴到公开 Issue。                                      |
| 备份恢复失败             | 使用原始恢复口令和未经修改的 `.amibackup`；错口令、损坏、截断、超大或未来 schema 文件会被主动拒绝。                                |
| Playwright 无法启动      | 安装三种浏览器，确认可以监听 `127.0.0.1:4399`，并停止残留的本地 mock server。                                                      |
| 发现安全问题             | 不要公开提交。请用[私密漏洞报告](https://github.com/mason2048/ai-memory-inspector/security/advisories/new)，复现数据必须完全虚构。 |
